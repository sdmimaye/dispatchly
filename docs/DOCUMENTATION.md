# Dispatchly documentation

Dispatchly is an outbox messaging library. Specs start in `docs/plan/`. Shipped work moves to `docs/feature/`. Bug records live in `docs/bug/`.

## Folders

- `docs/plan/` — work that has not shipped (`Proposed`, `Approved`, `In progress`)
- `docs/plan/archive/` — shipped or cancelled specs
- `docs/feature/` — shipped features
- `docs/bug/` — bug records
- `docs/arc42/` — architecture notes that grow with the library
- `docs/testing.md` — how to run tests

## Numbering

`####_short-description.md`, numbered independently in each folder. `0000_readme.md` is the index and template.
