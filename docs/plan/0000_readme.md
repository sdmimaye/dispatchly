# Plan documents

Specs for work that has not shipped. Status is exactly one of `Proposed`, `Approved`, `In progress`, or `Shipped`. Only `Approved` or `In progress` specs drive implementation.

## Template

```markdown
# Title

- Status: Proposed
- Summary:

## User story

## Acceptance criteria

## Non-goals

## Open questions

## Related
```
